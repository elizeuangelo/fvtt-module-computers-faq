    Hello terminal

    Start with a typewriter greeting, then print the operator and computer names. In FERRO, an optional first argument overrides the greeting name: ./hello "Agent Quinn". VANTAGE uses the current controller's name.

    terminal.clear();
    await terminal.typeLine("ESTABLISHING UPLINK...", { delay: 35 });
    await terminal.sleep(500);
    const operator = program.args[0] || program.controller.name;
    terminal.writeLine(`Welcome, ${operator}.`);
    terminal.writeLine(`Computer: ${program.computer.name}`);
    terminal.writeLine(`Operating system: ${program.os}`);
    audio.cue("success");

    Expected behavior

    The previous output clears. ESTABLISHING UPLINK... appears gradually, followed by the greeting, computer name, and OS ID. A success cue plays for open viewers, respecting their audio preferences. Output remains until Escape.

    Uses terminal.clear, terminal.typeLine, terminal.sleep, terminal.writeLine, program.args, program.controller, program.computer, program.os, and audio.cue.
