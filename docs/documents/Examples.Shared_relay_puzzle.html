    Shared relay puzzle

    Place this Program on two computers to let the party activate a relay on one machine and read its status on another. The status is shared across the current world.

    terminal.clear();
    const action = await terminal.choose("Relay control:", ["Check status", "Activate relay", "Deactivate relay"]);
    if (action === "Activate relay") {
      await save.world("example_relayOnline", true);
      audio.cue("success");
    } else if (action === "Deactivate relay") {
      await save.world("example_relayOnline", false);
    }
    const online = load.world("example_relayOnline") === true;
    terminal.writeLine(`RELAY: ${online ? "ONLINE" : "OFFLINE"}`);
    terminal.writeLine(online ? "The east entrance receives the access signal." : "Activate the relay from any connected computer.");

    Download the Program

    Expected behavior

    Choose Activate relay on one computer. Launch the Program on another and choose Check status to see RELAY: ONLINE. Deactivate relay resets it to offline. The state persists across restarts. It prints status at the time of the read; it does not create a continuously updating dashboard or actually unlock a folder.

    Uses terminal.choose, save.world, load.world, and audio.cue. Remote changes become available through Foundry synchronization; an awaited save is visible to the executing GM before the helper returns.
